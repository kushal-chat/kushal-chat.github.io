This blog is built from plain Markdown files. To publish something, create a file in `posts/` and run the build.

## Adding a post

Drop a Markdown file into the `posts/` folder and push. That is all. A GitHub Action rebuilds the [blog index](index.html), the News list on the home page, and the History essays list automatically.

To preview locally, run `node build.mjs`, or scaffold a file with:

```bash
node build.mjs new "My post title" ml,history
```

## What you can write

- Standard Markdown: **bold**, *italic*, [links](https://example.com), lists, quotes and tables.
- Math with KaTeX, such as $e^{i\pi} + 1 = 0$, or in display form:

$$ D_{\mathrm{KL}}(P \| Q) = \sum_i p_i \log \frac{p_i}{q_i} $$

- Interactive visualizations, embedded with one line of HTML. See the posts on [Stiefel gradient descent](stiefel-gradient-descent.html) and [information theory](information-theory.html).

> Set `draft: true` in the front matter to keep a post out of the build until it is ready.
